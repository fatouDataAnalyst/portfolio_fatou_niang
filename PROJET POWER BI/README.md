# PROJET POWER BI – ANALYSE MARKETING IFOOD

## 1. Présentation du projet
Analyse des données clients et des campagnes marketing
afin d'améliorer la performance commerciale de iFood.

## 2. Problématique
La campagne test menée auprès de 2 240 clients
a généré une perte nette de 3 046 MU.

## 3. Objectifs
- Analyser le comportement des clients.
- Identifier les segments les plus réceptifs.
- Évaluer les performances des campagnes.
- Améliorer la rentabilité marketing.

## 4. Outils utilisés
- Power BI
- Power Query
- Visualisation de données

## 5. Résultats
- 2 240 clients analysés
- Taux de réponse : 15 %
- Coût : 6 720 MU
- Revenus : 3 674 MU
- Perte nette : -3 046 MU

## 6. Recommandations
- Mieux cibler les clients.
- Prioriser les campagnes performantes.
- Personnaliser les offres.
- Réduire les coûts de prospection.
